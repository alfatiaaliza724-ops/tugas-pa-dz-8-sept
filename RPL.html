REKAYASA PERANGKAT LUNAK

Pengembangan Perangkat Lunak dan Gim (PPLG) adalah satu bidang profesi yang mendalami cara-cara pengembangan perangkat lunak termasuk pembuatan, pemeliharaan, manajemen organisasi, dan manajemen kualitas.

KOMPETENSI DASAR

  • Pemrograman Dasar
  • Jaringan Komputer Dasar
  • Sistem Komputer
  • Kerja Proyek
  • Administrasi Database
  • Pemrograman Web dan Perangkat Bergerak
  • Pemodelan Perangkat Lunak
  • Java Mobile
  • Android Studio

TUJUAN PEMBELAJARAN KOMPETENSI REKAYASA PERANGKAT LUNAK

Tujuan Pembelajaran Jurusan Rekayasa Perangkat Lunak (RPL) di Sekolah Menengah Kejuruan (SMK) bertujuan untuk membekali siswa dengan pengetahuan, keterampilan, dan sikap profesional dalam bidang pengembangan perangkat lunak. Adapun tujuan pembelajaran secara spesifik meliputi:

Menguasai Dasar-Dasar Pemrograman: Siswa mampu memahami konsep dasar pemrograman, struktur data, algoritma, dan logika pemrograman untuk membangun aplikasi perangkat lunak yang efisien.

Mengembangkan Aplikasi Perangkat Lunak: Siswa dilatih untuk merancang, mengembangkan, dan menguji aplikasi berbasis desktop, web, maupun mobile menggunakan berbagai bahasa pemrograman dan teknologi terkini.

Memahami Sistem Basis Data: Siswa mampu mengelola basis data, termasuk merancang, mengimplementasikan, dan mengintegrasikan database ke dalam aplikasi perangkat lunak.

Menerapkan Prinsip Rekayasa Perangkat Lunak: Siswa mempelajari metodologi pengembangan perangkat lunak seperti SDLC (Software Development Life Cycle) untuk menghasilkan produk yang berkualitas dan sesuai kebutuhan pengguna.

Mengembangkan Keterampilan Kolaborasi dan Profesionalisme: Siswa dibekali kemampuan bekerja dalam tim, berkomunikasi efektif, serta memahami etika profesi di industri teknologi informasi.

Persiapan Karir dan Kewirausahaan: Siswa disiapkan untuk bekerja sebagai pengembang perangkat lunak, teknisi IT, atau wirausaha di bidang teknologi informasi, serta memiliki kemampuan beradaptasi dengan perkembangan teknologi.
